# Element Ventures (Canada) Ltd.

**Sovereign Operating Intelligence™** — open infrastructure for supply-chain and decision capability that stays under the control of the jurisdiction that relies on it.

Vancouver, Canada · [elementventures.ca](https://elementventures.ca)

## Our open-core model

We publish an **open tier** under Apache-2.0: public-records data, shared schemas, documentation, research and evaluation tooling. Core engines (ontology, registry, decision and assessment engines) are maintained privately. This split is deliberate and is stated in each repository.

## Contributing

Each repository has its own contribution guide and handling rules. External contributions require signing our Contributor Licence Agreement (CLA). Look for issues labelled `good first issue`.

## Security

Please do **not** open public issues for security reports. Use the **Security → Report a vulnerability** button on the relevant repository. If you cannot use GitHub, email tleroy@elementventureslp.com with "Security" in the subject line. We aim to acknowledge reports within 5 business days.
